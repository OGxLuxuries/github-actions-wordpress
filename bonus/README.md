# WordPress and RDS bonus

This separate Terraform stack adapts the course's WordPress and RDS activity for GitHub Actions. It creates a WordPress EC2 host and a private RDS MySQL database. Its S3 state key is separate from the core activity.

Run **WordPress_RDS_bonus** in GitHub Actions with `apply`. The successful run prints `ec2_public_ip` and `wordpress_url`. Open the URL and wait for the WordPress installation screen before taking screenshots.

The handout asks for three bonus screenshots:

1. The successful Terraform apply output.
2. WordPress running at the `ec2_public_ip` from the apply output.
3. The successful Terraform destroy output.

After capturing the first two screenshots, run **WordPress_RDS_bonus** with `destroy`, then capture the third screenshot. RDS and EC2 incur charges until destroyed. The database password is generated by Terraform and stored in encrypted S3 state; do not publish the state file or workflow logs containing secrets.
